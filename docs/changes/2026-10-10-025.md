# 2026-10-10: Task 025, the run flow (main part)

Author: Agent A. Branch: `a/025-run-flow`, on top of the two contract commits

## What changed and why

A whole solo run of floor 1, from a seed to the boss reward, now runs through `Core.apply()`, with
every node type (task 025, GDD "Run structure", G14–G26 answered "accept").

- **New run** (`core/run/new_run.gd`): `start(ruleset, run_seed, dude_ids)` returns the first state:
  Dudes from data by seat with fresh card_uids and starting Gear (via `core/combat/party.gd`),
  `START_DOLLA_BILLS` (G20), `BASE_BREW_SLOTS`, floor 1's map, `run_phase` `"map"`, event
  `floor_started`. Not a request (there is no state yet). Checks every run constant once.
- **Node flow** (`core/run/node_flow.gd`): `vote_node` (votes wait for every Dude; ties go to the
  Designated Driver) moves the party and resolves the node in the same request; `choose_reward`
  answers an offer; a run fight's end gives rewards or ends the run (`after_request_in_place`).
- **Rewards** (`core/run/rewards.gd`): Brawl (10–20 Dolla Bills, 40% Brew, 1 of 3 cards), Rival
  (25–35, a Gear, 1 of 3 cards), Boss (full heal, 1 of 3 Boss Gear), Mimic (its dropped Brew);
  revive after a won fight; Dad's Platinum Card through `GearTriggers.fight_dolla_bills`.
- **The Tailgate** (`core/run/tailgate.gd`): Nap heals `TAILGATE_NAP_HEAL` of max HP (rounded down);
  Lift upgrades one card that has an upgrade (G15).
- **Baileys** (`core/run/baileys.gd`): G21 stock and prices, every Brew sold as an option of kind
  `shake` (the client labels it Shake; nothing in the code names a drink), Medical Card on every price
  including removal (G26), removal 75 rising by 25, Regret not removable, leave with -1.
- **Loot** (`core/run/loot.gd`): free Gear from the Loot pool (G24, G28), or 1 time in 4 a Mimic
  Cooler fight (G19, `LOOT_MIMIC_CHANCE`, `encounters` stream).
- **Side Quests** (`core/run/side_quests.gd`, `core/run/side_quest_ops.gd`): the format's operations,
  the `side_quest` stream for the pick and every gamble, `dumb_options_taken`, G23 (bet needs 50),
  G24 (random Gear from the Loot pool), G25 (pending statuses).
- **Encounters** (`core/run/encounters.gd`): G19's groups as data, drawn on `encounters`; the first
  `EARLY_BRAWL_COUNT` Brawls only from `early` groups.
- **Shared helpers**: `core/run/offers.gd` (offers), `core/run/grants.gd` (cards, Brews, Dolla Bills,
  HP, upgrades between fights), `core/run/pools.gd` (pools, G21 odds, prices),
  `core/run/draws.gd` (in-place draws; probabilities in whole millionths, never floats),
  `core/run/run_constants.gd` (the constant check).
- **Core lane, small marked edits** ("Task 025"):
  - `core/core.gd`: routes `vote_node` and `choose_reward` to the node flow and calls its
    after-request hook after Gear's fight_end point.
  - `core/ruleset/ruleset.gd`: folders `data/side_quests/` and `data/encounters/`; checks encounter
    enemy ids and Side Quest operations and card ids.
  - New `core/combat/upgrades.gd`: applies a card's `upgrade` paths. `core/combat/play.gd`,
    `powers.gd` and `piles.gd` read a copy's definition through it, so a Lifted card plays upgraded.
    Before, an upgraded copy with an upgrade was refused as "unplayable".
  - New `core/combat/pending_statuses.gd`, called from `core/combat/fight.gd` right after
    `fight_started` (G25).
  - `core/ops/ops.gd` and `data/constants.json` are not touched here (task 031 is editing them).
- **Tests**: `tests/run/` (new run, node flow, Tailgate, Baileys, Side Quests, formats, the
  fixed-seed whole run) with fixtures in `tests/run/fixtures/`; `tests/core/combat/test_upgrades.gd`.
  `tests/core/ruleset/test_ruleset.gd` now uses `data/events/` as its unknown folder, and
  `tests/core/combat/test_core_apply.gd` checks an upgraded copy whose upgrade cannot apply
  (new fixture card `neutral_test_bad_lift`).
- **Recorded hashes re-recorded** for SCHEMA_VERSION 8, after every outcome assertion passed:
  `SAMPLE_HASH` `d1c0d10c…`, `test_fixed_seed_fight` `dfbba3b6…`, `test_fixed_seed_status_fight`
  `5bb160a6…`, `test_tom_fixed_seed_fight` `0d54fed1…`, `test_goblin_king_chad` `49845798…`.
  New: `test_run_fixed_seed` `221de4ce…`.
- **Rule gaps** G54–G61 added to `docs/proposals/solo-slice-rule-gaps.md`, unanswered, each built as
  its suggested default.
