# 2026-10-10: Task 004, data validation tests

## What changed

- `tools/data_files.gd`: a reader that returns every file under `data/` as
  `{repo-relative path: text}`, for `core/ruleset/ruleset.gd` `build()`. Tests, tools and the
  client share it.
- `tests/data/test_data_files.gd`: runs `build()` on the real `data/` folder on every test run, and
  proves that broken files and unknown folders fail with their path.

## Why

So a content PR with a mistake fails CI instead of failing at runtime. The checks themselves live
in `build()` (task 005); this task makes them run on the real data.

## Fields, variables and constants

Added (documented in their files):
- `tools/data_files.gd`: `DATA_DIR` (`"data"`), `read_all(root)`.
- `tests/data/test_data_files.gd`: `BROKEN_JSON` (fixture text).

Nothing renamed or removed.
