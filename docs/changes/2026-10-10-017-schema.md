## Why

GDD "Floor 1: The Basement": eleven enemies whose behavior is more than a plain move. Task 010
(content) said these need fields the shape did not have. Each field is generic, so later enemies
can reuse it with their own numbers, and every number stays in the enemy's data file, where the
content lane tunes it, rather than in code or in `constants.json`.

| GDD behavior | Expressed as |
| --- | --- |
| Goblin Pledge: the last goblin standing calls one more Pledge | `tags: ["goblin"]`, a `move_rules` entry with condition `last_of_tag`, and the op `summon_enemy` |
| Goblin Bouncer: alternates 8 Guard and a 9-damage hit; Checks ID: 1 Noodle Arms | `pattern` (task 011) and existing ops; nothing new |
| Keg Slime: at half HP splits into two 10-HP Foam Slimes | `split` |
| Dorm Rats: each bite steals 5; flee on turn 4; killing one returns its haul | op `steal_dolla_bills`, `haul` on the enemy, `move_rules` with `turn_at_least` and the op `flee` |
| Skeleton Intern: every other turn shuffles Paperwork into the target's deck | `pattern` and task 015's op `add_card` |
| Boo-zer: Faded every other turn, at most 1 damage per hit | `periodic_statuses` with status `faded`, constant `FADED_MAX_DAMAGE` |
| Mimic Cooler: always drops a Brew | `drops_brews`, reported in `combat.brews_dropped` and `brew_dropped` |
| Kobold RA: Noise Complaint | a `triggers` entry `on: "cards_played"` |
| Goblin Shot-Caller: arrives with 2 Pledges; every other turn Swole to all goblins or replaces a dead Pledge | `arrives_with`, `move_rules` with `turn_cycle` and `count_below`, op `gain_swole` with `tag` |
| Hall Monitor Golem: every third card adds Detention | a `triggers` entry `on: "cards_played"` with `repeat: true` and task 015's `add_card` |
| Sewer Gator: gains 2 Swole on unblocked damage | a `triggers` entry `on: "unblocked_damage"` and op `gain_swole` |

`haul` lives on the enemy because the GDD keeps per-player things per player: in co-op one rat can
carry Dolla Bills from several Dudes, and each gets their own part back. `drops_brews` is copied
onto the enemy when it joins a fight because an enemy dies inside the damage code, which has the
state but not the content data. `brews_dropped` is the "result field" task 017 asks for: the core
reports the drop and the run lane grants it.

## Fields added, renamed or removed

### Enemy definition (`enemy_def.gd`), all optional

| Field | Type | Meaning |
| --- | --- | --- |
| `tags` | list of text | Groups the enemy belongs to, for example `"goblin"`. No duplicates |
| `arrives_with` | list of enemy ids | Enemies that start the fight with it, placed right after it in order. One level only |
| `move_rules` | list of `{move_id, when}` | Rules tried in order at each intent; the first whose conditions all hold picks the move. Otherwise the pattern or random choice decides. A rule-picked intent counts as a pattern step |
| `move_rules[].move_id` | text | One of the enemy's move ids |
| `move_rules[].when` | list of conditions | All must hold. A condition is `{"if": kind, ...}`; kinds and their fields are in `CONDITIONS`: `last_of_tag {tag}`, `turn_at_least {turn}`, `turn_cycle {every, first_turn}`, `count_below {def_id, count}`, `count_at_least {def_id, count}`, `hp_below_percent {percent}` |
| `triggers` | list of `{id, on, effects, ...}` | Effects run outside its own turn. `on: "cards_played"` with `cards` (int, 1 or more) and `repeat` (bool); `on: "unblocked_damage"` with no extra fields. The effects' actor is the enemy, their only target the Dude named by the kind, and damage in them is not attack damage (G3) |
| `split` | `{into, count, at_hp_percent}` | Replaced by `count` enemies of definition `into` once its HP is above 0 and at or below `at_hp_percent` % of max HP (1..99) |
| `periodic_statuses` | list of `{status, every, first_turn}` | Has `status` (only `faded` so far) on turns `first_turn`, `first_turn + every`, ... and not on the others |
| `drops_brews` | int, 0 or more | Brews dropped on death. Absent means 0 |

### State

| Field | Where | Type | Meaning |
| --- | --- | --- | --- |
| `haul` | `combat.enemies[]` (`enemy_state.gd`) | map player_id -> int, each 1 or more | Dolla Bills the enemy stole and carries. Returned to each player when it dies; lost when it flees |
| `drops_brews` | `combat.enemies[]` (`enemy_state.gd`) | int, 0 or more | Copied from the definition when the enemy joins the fight |
| `brews_dropped` | `combat` (`combat_state.gd`) | int, 0 or more | Brews dropped by enemies that died in this fight; the run lane grants them if the fight is won |

### Events (`event.gd`)

| Type | Fields | When |
| --- | --- | --- |
| `enemy_fled` | `enemy_uid` | An enemy left the fight alive (Dorm Rats) |
| `enemy_split` | `enemy_uid` | An enemy split and was removed; `enemy_spawned` events follow |
| `dolla_bills_stolen` | `enemy_uid`, `player_id`, `amount` | An enemy stole Dolla Bills (after the Dude's `dolla_bills_changed`) |
| `dolla_bills_returned` | `enemy_uid`, `player_id`, `amount` | A dead enemy's haul went back (after `dolla_bills_changed`) |
| `brew_dropped` | `enemy_uid`, `count` | A dying enemy dropped Brews (after `enemy_died`) |
| `enemy_triggered` | `enemy_uid`, `trigger_id`, `target_id` | One of an enemy's triggers fired; its effects follow |

### Status ids (`README.md`)

| Id | Meaning |
| --- | --- |
| `faded` | Boo-zer's Faded. In `statuses` with 1 stack while active; set and cleared only by `periodic_statuses`; never worn off or applied by `apply_status` |

| Constant | Where | Change |
