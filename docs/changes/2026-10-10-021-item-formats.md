## What changed

All changes are additive: two new files and two new rows in a table. No existing field changes.

- **`core/schema/gear_def.gd`** (new): the shape of a Gear file in `data/gear/`, with `check()`.
- **`core/schema/brew_def.gd`** (new): the shape of a Brew file in `data/brews/`, with `check()`.
- **`core/schema/README.md`**: the two files in the table. The note "Gear, Brew and Side Quest
  formats are not here yet" now names only Side Quests (task 025).
- **`tests/core/schema/test_item_defs.gd`** (new, 4 tests): valid Gear and Brews, including the
  header examples parsed from JSON text, and one failing case per rule.

No state shape changes here, so `SCHEMA_VERSION` is unchanged by this commit. The ruleset does not
load `data/gear/` and `data/brews/` until task 021's core commit; until then a file there is still
"not in a known data folder".

## Why

The GDD lists Gear and Brews in tables but gives no data format (task 021, CLAUDE.md "Content is
data"). Task 014 (Agent B) writes the slice's 13 Gear and 8 Brews in these formats.

## Fields and constants added

### Gear definition (`gear_def.gd`)

| Name | Type | Meaning |
| --- | --- | --- |
| `id` | Text | Unique key, snake_case, equal to the file name. Dude Gear starts with its owner (`tom_arm_wrestling_table`); general and Boss Gear have no prefix (`medical_card`). Never changes after merge. |
| `name` | Text | Name shown to players. |
| `owner` | Text, one of `OWNERS` | A Dude (`tom`, `cheney`, `nate`, `grube`, `ethan`: Dude Gear), `general` or `boss`. |
| `rarity` | Text, one of `RARITIES` | `starter`, `common`, `uncommon`, `rare` or `boss` (G28). `boss` exactly when `owner` is `boss`. |
| `text` | Text | Rules text shown to players, in the GDD's wording. Boss Gear states upside and downside. |
| `stats` | Map, stat → int | Stat changes that hold while the Gear is owned, applied once when gained. Keys from `STATS`; values non-zero (negative allowed, as in Protein Bucket's −1 Chill). `{}` for none. |
| `triggers` | List of trigger | Effects that run at a trigger point. `[]` for none. |
| `modifiers` | List of modifier | Numbers other rules read. `[]` for none. |
| trigger `when` | Text, one of `WHENS` | `fight_start`, `first_turn`, `fight_end`, `card_played`, `ick_applied`. |
| trigger `target` | Text, one of `TRIGGER_TARGETS` | `self`, `all_enemies`, `all_dudes`, `trigger_target` (the Ick's enemy, or the played card's targets). |
| trigger `effects` | List | Effect operations, as on a card. |
| trigger `card_type` | Text, optional | `card_played` only: only cards of this type. |
| trigger `min_cost` | int, optional | `card_played` only: only cards whose int cost is at least this. |
| trigger `hp_below_percent` | int 1..100, optional | Fire only while the owner's HP is below this percent of max HP. |
| trigger `amount_per_stack` | bool, optional | `ick_applied` only: each effect's `amount` is multiplied by the Ick applied. |
| modifier `kind` | Text, one of `MODIFIER_KINDS` | `card_damage`, `shop_price_percent`, `fight_dolla_bills_percent`. |
| modifier `amount` | int, 0 or more | Damage added per hit (`card_damage`) or percent of normal (the two `_percent` kinds). |
| modifier `card_type` / `min_cost` | Text / int, optional | `card_damage` only: the card filter, as for triggers. |
| `DUDE_OWNERS`, `OWNERS`, `RARITIES`, `STATS`, `WHENS`, `TRIGGER_TARGETS`, `WHENS_WITH_TRIGGER_TARGET`, `MODIFIER_KINDS`, `CARD_MODIFIER_KINDS` | Constants | The allowed values above. Change only through a contract PR. |
| `SPEC`, `TRIGGER_SPEC`, `TRIGGER_OPTIONAL`, `MODIFIER_SPEC`, `MODIFIER_OPTIONAL` | Constants | The field tables `check()` uses. |
| `MAX_PERCENT` | Constant, 100 | Highest `hp_below_percent`. |

### Brew definition (`brew_def.gd`)

| Name | Type | Meaning |
| --- | --- | --- |
| `id` | Text | Unique key, snake_case, equal to the file name (`light_beer`). Never changes after merge. |
| `name` | Text | Name shown to players. At Baileys it is shown under the shop label "Shake" (G29). |
| `rarity` | Text, one of `RARITIES` | `common`, `uncommon` or `rare` (GDD Brews table). |
| `text` | Text | Rules text shown to players, both the co-op and the solo rule if it has one. |
| `target` | Text, one of `TARGETS` | `none`, `self`, `enemy`, `all_enemies`, `all_dudes`, `ally` (not built yet). |
| `effects` | List | Effect operations, as on a card. |
| `solo` | Object, optional | `{"target", "effects"}` used instead of the Brew's own when `party_size` is 1 (Smelling Salts). |
| `RARITIES`, `TARGETS` | Constants | The allowed values above. |
| `SPEC`, `OPTIONAL`, `SOLO_SPEC` | Constants | The field tables `check()` uses. |
