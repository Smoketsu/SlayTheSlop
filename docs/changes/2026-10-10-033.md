# 2026-10-10: Task 033, add_card "lasts" option (Beer Helmet's fight-only Hangover, I7)

Author: Agent A. Branch: `claude/brave-cerf-to5qlg`.

## What changed

- `core/ops/add_card.gd`: optional field `lasts`. Its only value, `"fight"`, makes every copy last
  this fight only, even when the card's definition lasts the run. A fight-only copy stays out of
  the run deck. `create_in_place` takes an optional `fight_only` argument.
- `core/combat/card_triggers.gd`: at fight end a copy is removed when its definition lasts
  `"fight"` **or** it is not in the run deck. A removed copy also leaves `powers`, so a fight-only
  Power in play no longer leaves a dangling uid there.
- `core/ops/README.md`: `add_card` and "Card triggers" describe both.
- Tests: `tests/core/ops/test_add_card_lasts.gd` (new, 3 tests); Beer Helmet tests in
  `tests/core/items/test_pending_ops.gd` (1 changed, 1 new); fixtures `fixtures.gd` `give()` (the
  copy joins the run deck), `junk_fixtures.gd` `own()`, `item_fixtures.gd` `beer_helmet`.

## Why

I7 is accepted in the decision log (#54): Beer Helmet's Hangover lasts one fight. Before this, the
helmet added a run-long Hangover to the deck every fight. Agent B can now add `"lasts": "fight"` to
`data/gear/beer_helmet.json` (task 014, #58).

## Added, renamed or removed

| Name | Where | Meaning |
| --- | --- | --- |
| `lasts` | `add_card` effect field (`FIELDS`) | Optional text, one of `LASTS_VALUES`. `"fight"`: every copy lasts this fight only and stays out of the run deck. Left out: the card definition's `lasts` decides. |
| `LASTS_VALUES` (`["fight"]`) | `core/ops/add_card.gd` const | Values `lasts` may have. A copy may last less than its definition, never more. |
| `fight_only` | parameter of `AddCard.create_in_place` | Bool, default `false`. `true` makes this copy fight-only whatever its definition says. |
| `fight_only` | local in `AddCard.run` | True when the effect has `lasts: "fight"`. |

No state field, event or constant was added, renamed or removed: "fight-only" is "owned but not in
`dude_state.deck`", which the deck's existing meaning ("every card_uid this Dude owns for the run")
already implies. `SCHEMA_VERSION` is unchanged.
