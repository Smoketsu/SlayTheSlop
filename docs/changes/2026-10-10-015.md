# 2026-10-10: Task 015, Junk card rules

Author: Agent A. Branch: `a/015-junk-cards`. Lane: `core`. Built **in parallel with task 013**
rather than after it (the lead fixed the split), so nothing here uses what 013 adds. The contract
part (card definition fields, rarity `special`, event `card_removed`) is in its own first commit
and its own change file: `docs/changes/2026-10-10-015-schema.md`.

## What changed

- **`core/ops/add_card.gd`** (new): the `add_card` op. It creates copies of a card for a Dude, in
  the draw pile (on top, or with `shuffle_in` at a random position from the receiving Dude's
  `shuffle` stream), the discard pile or the hand, `count` times. Run cards also join the run deck.
  Emits `card_created`. Lands on the actor when it is a Dude, and on the targeted Dudes for an enemy
  move. Also has `create_in_place()` (reusable by run-lane rewards) and `is_fight_only()`.
- **`core/ops/lose_hype.gd`** (new): the `lose_hype` op (Hangover). Hype stops at 0.
- **`core/ops/self_damage.gd`** (new): the `self_damage` op (Bedbugs, Burn). It is not attack
  damage (G3): exactly `amount`, through Guard and then HP, `source_id` `""`. Task 013 owns this op
  name too; the lead keeps one version.
- **`core/ops/ops.gd`**:
  - Registers the three ops.
  - The op context now carries `cards` (the ruleset's card definitions), which `add_card` needs.
- **`core/combat/card_triggers.gd`** (new): the rules for cards that act without being played:
  - `draw_in_place` draws with `on_draw` triggers.
  - `end_of_turn_in_hand_in_place` runs Burn.
  - `play_limit_reached` is Detention's limit.
  - `remove_fight_only_in_place` removes fight-only cards when the fight ends.
- **`core/combat/fight.gd`**: small edits marked "Task 015":
  - Refresh draws through `CardTriggers.draw_in_place`. `_refresh_in_place` now takes `ruleset`.
  - If a Refresh trigger decides the fight, the fight ends before the player phase.
  - End of turn runs `on_end_of_turn_in_hand` before each hand is discarded. If that decides the
    fight, the enemies do not act.
  - **`finish_if_decided_in_place` now takes `ruleset` as its first argument**. After
    `fight_ended` it removes fight-only cards.
- **`core/combat/play.gd`**: `check()` returns `unplayable` while a `play_limit_in_hand` card is in
  hand and the limit is reached (Detention).
- **`core/core.gd`**: passes `ruleset` to `finish_if_decided_in_place`.
- **`core/ruleset/ruleset.gd`**: `build()` reports an `add_card` whose `card_id` is not a card. It
  checks card effects, card trigger lists and enemy moves (`_check_added_cards`).
- **`core/ops/README.md`**: entries for `add_card`, `lose_hype` and `self_damage`, a "Card
  triggers" section, and the six Junk cards written as data for task 008.
- **Tests:**
  - `tests/core/combat/junk_fixtures.gd` (new): the six Junk cards with the ids task 008 should
    use, plus test cards and enemies that add Junk.
  - `tests/core/combat/test_junk_cards.gd` (new, 13 tests): one or more per Junk card, using the
    GDD numbers, and fight-only removal.
  - `tests/core/ops/test_junk_ops.gd` (new, 11 tests): `add_card` to every pile, `shuffle_in` with
    a fixed seed (`SHUFFLED_POSITION` 3 for seed 2016), `count`, recipients, unknown ids,
    `lose_hype` and `self_damage`.

No recorded hash changed. The Refresh draw now goes one card at a time, which uses the shuffle
stream exactly as before, so `test_fixed_seed_fight` and `test_fixed_seed_status_fight` still match.

## Variables, fields and constants added

| Name | Where | Meaning |
| --- | --- | --- |
| `add_card` | op | Fields `card_id` (text), `to` (`draw_pile` / `discard_pile` / `hand`), `shuffle_in` (bool, optional, draw pile only), `count` (int ≥ 1, optional, default 1) |
| `lose_hype` | op | Field `amount` (int ≥ 0): Hype the actor loses, stopping at 0 |
| `self_damage` | op | Field `amount` (int ≥ 0): non-attack damage the actor takes, through Guard then HP |
| `cards` | op context (`ops.gd` `make_context`) | `ruleset.cards`, read-only, card id → definition |
| `AddCard.NEEDS_TARGET` | `add_card.gd` | `true`: enemy intents with `add_card` aim at Dudes |
| `AddCard.DEFAULT_COUNT` | `add_card.gd` | 1, copies per effect without `count` |
| `AddCard.CARD_UID_PREFIX` | `add_card.gd` | `"c"`, must equal `party.gd` `CARD_UID_PREFIX` |
| `AddCard.FIGHT_ONLY` | `add_card.gd` | `"fight"`, the `lasts` value of fight-only cards |
| `AddCard.DESTINATIONS` | `add_card.gd` | The allowed `to` values |
| `AddCard.SHUFFLE_DESTINATION` | `add_card.gd` | `"draw_pile"`, the only `to` that `shuffle_in` works with |
| `AddCard.FIELDS`, `LoseHype.FIELDS`, `SelfDamage.FIELDS` | op files | Each op's fields and their types |
| `LoseHype.NEEDS_TARGET`, `SelfDamage.NEEDS_TARGET` | op files | `false`: both land on the actor |
| `SelfDamage.NO_SOURCE` | `self_damage.gd` | `""`, the `source_id` used for damage with no attacker |
| `CardTriggers.FROM_DECK` | `card_triggers.gd` | `"deck"`, the `card_removed.from` value for a copy that was in no pile |
| `SHUFFLED_POSITION` | `test_junk_ops.gd` | 3, the recorded fixed-seed position |

Renamed: nothing. Changed signatures: `Fight.finish_if_decided_in_place(ruleset, state, events)`
(was `(state, events)`) and the private `Fight._refresh_in_place(ruleset, state, dude_index, events)`.
Nothing removed.

## Merged with task 013 (lead)

- `core/ops/self_damage.gd` is a single file shared by tasks 013 and 015. It keeps 013's `uid`. From 015 it takes `NO_SOURCE` (`source_id ""`) and the rule that no damage happens once the fight is decided. From 013 it takes the rule that `amount` 0 does nothing. Task 013's Skull Bash test and `test_actor_kinds` now expect `source_id ""`.
- `core/ops/draw.gd` (task 013) now draws through `CardTriggers.draw_in_place`, so `on_draw` runs (new test `test_draw_op_runs_on_draw` in `tests/core/combat/test_junk_cards.gd`).
- `Ops.make_context` now returns both `"ruleset"` (013) and `"cards"` (015). New local variable:
  - `content`: the real ruleset. When an op context is passed in place of a ruleset, it is unwrapped from that context's `"ruleset"`.
- `core/core.gd`: the `use_bro_move` path passes `ruleset` to `Fight.finish_if_decided_in_place`.
