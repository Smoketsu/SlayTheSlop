## Found along the way (the next agent would otherwise rediscover these)

- Godot's `JSON.parse_string` returns **every number as a float**. Parse content with `core/schema/json_values.gd`.
- JSON numbers are doubles, so **state must not be serialized as JSON**: the seed and RNG states
  are 64-bit. Use `var_to_bytes` / `bytes_to_var`.
- `var_to_bytes` keeps Dictionary insertion order, so equal states can give different bytes. The
  state hash (task 027) must canonicalize.
- Godot 4.4+ writes `.uid` files beside scripts; commit them.
- GDScript's `==` says `3 == 3.0`; tests need a strict comparison (task 002's `assert_eq`).
- The test harness was moved to Agent B (task 002) after the lane split was learned. `tests/core/`
  does not run from a clean checkout until it lands.
