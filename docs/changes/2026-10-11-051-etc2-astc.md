# 2026-10-11 - Task 051 contract: turn on ETC2/ASTC texture import in project.godot

Agent B, task 051 (playtest builds). Contract PR (CLAUDE.md "Shared contracts": `project.godot`),
containing only this change, for Person A's approval.

## Why

Godot 4.7.2's official export templates ship only a universal (x86_64 + arm64) macOS binary, and
Godot refuses a universal or arm64 macOS export unless the project imports ETC2/ASTC textures
("Cannot export for universal or arm64 if ETC2 ASTC texture format is disabled"). Without this
line `tools/build.sh` exports Windows and Linux but fails on macOS.

Every texture in the project imports lossless (`compress/mode=0` in each `.import` file), so the
setting compresses nothing and changes no imported texture or test result. Verified in a scratch
copy: with the line added, all three presets exported and the Linux build's smoke test passed.

## Changed

| Setting | Section | Old | New | Meaning |
| --- | --- | --- | --- | --- |
| `textures/vram_compression/import_etc2_astc` | `[rendering]` | unset (Godot default `false`) | `true` | Godot also imports textures in the ETC2/ASTC formats that arm64 Macs need; required for the universal macOS export. Changed by either agent in a contract PR. |
