Author: Agent A. Branch: `a/021-gear-and-brew-format-and-effects`. Lane: `core`. The contract parts
are in their own commits and change files: `2026-10-10-021-item-formats.md` (Gear and Brew formats)

## What changed

- **`core/combat/gear_triggers.gd`** (new): gaining Gear (`gain_in_place`, stats applied once), the
  trigger points `fight_start`, `first_turn`, `fight_end`, `card_played`, `ick_applied`, the
  `card_damage` modifier (`card_effects`), the percent modifiers (`percent_of`, `shop_price`,
  `fight_dolla_bills`) and `check()` for content tests.
- **`core/combat/brews.gd`** (new): the `use_brew` request (`check`, `resolve_in_place`, solo variant).
- **New ops** in `core/ops/`: `heal`, `gain_stat` (with `duration: "fight"` and
  `undo_fight_changes_in_place`), `remove_debuffs`, `tap_cards`, `prevent_pass_out`. Registered in
  `ops.gd`; the op context now also carries `ruleset`.
- **Hooks**, each marked "Task 021": `fight.gd` (fight_start before turn 1, first_turn after its
  Refresh), `play.gd` (Championship Ring's raised effects, Body Spray after each effect, card_played
  after the card is in its pile), `core.gd` (`use_brew` routing and checks; end-of-fight Gear after
  any request that ends the fight), `party.gd` (starting Gear through `gain_in_place`),
  `bodies.gd` (a pass-out save keeps a Dude at its HP instead of passing out).
- **`core/ruleset/ruleset.gd`**: loads `data/gear/` and `data/brews/` (`KINDS`, ruleset keys `gear` and
  `brews`) and checks each Dude's `starting_gear`.
- **`core/ops/README.md`**: the five ops, a "Gear" section (trigger points, targets, modifiers) and a
  "Brews" section.
- **`docs/proposals/item-rule-gaps.md`** (new): I1–I9, the Gear and Brew rules the GDD does not state,
  each built as its suggested default.
- **Tests:** `tests/core/items/` (new: `item_fixtures.gd`, `test_gear.gd` 19 tests, `test_brews.gd`
  9 tests, `test_fixed_seed_items_fight.gd` 2 tests); `tests/core/ruleset/test_ruleset.gd`
  (`test_starting_gear_is_not_checked_yet` replaced by `test_starting_gear_must_name_gear`, new
  `test_bad_gear_and_brew_files_are_reported`, Gear and Brews in the valid set);
  `tests/core/combat/fixtures.gd` and `tests/core/ai/ai_fixtures.gd` (a `GEAR` map with `test_gear`,
  test_dude's starting Gear, now that starting Gear is checked).

## Variables, fields and constants added

No tuning constants were added: every Gear and Brew number is content and lives in its data file.

| Name | Where | Meaning |
| --- | --- | --- |
| `ICK_STATUS` | `gear_triggers.gd` | `"ick"`: the status whose application sets off `ick_applied` |
| `AMOUNT_FIELD` | `gear_triggers.gd` | `"amount"`: the effect field `amount_per_stack` multiplies |
| `DAMAGE_OP` | `gear_triggers.gd` | `"damage"`: the op whose amount `card_damage` raises |
| `WHOLE_PERCENT` | `gear_triggers.gd` | 100: percent meaning "unchanged" |
| `WON` | `gear_triggers.gd` | `"won"`: the fight result on which `fight_end` fires |
| `SOLO_PARTY_SIZE` | `brews.gd` | 1: party size at which a Brew's `solo` variant is used |
| `FIELDS` | each new op file | The op's fields and types (`heal`: `amount`; `gain_stat`: `stat`, `amount`, `duration`; `tap_cards`: `card_type`; `prevent_pass_out`: `hp`) |
| `NEEDS_TARGET` | each new op file | `false` for all five: none aims an enemy move at Dudes |
| `DURATIONS` | `gain_stat.gd` | `["fight"]`: allowed `duration` values |
| `ENEMY_STATS` | `gain_stat.gd` | `["swole"]`: the only stat an enemy has |
| `FLOORS` | `gain_stat.gd` | Lowest value per stat: `max_hp` 1; `hype_per_turn`, `draw_per_turn`, `brew_slots` 0 |
| `GEAR` | `tests/core/combat/fixtures.gd` | Test Gear by id (`test_gear`, which does nothing) |
| op context `ruleset` | `core/ops/ops.gd` `make_context` | The whole read-only ruleset, for ops that read definitions |
| ruleset `gear`, `brews` | `core/ruleset/ruleset.gd` | Gear and Brew definitions by id |
| `KINDS` `data/gear/`, `data/brews/` | `core/ruleset/ruleset.gd` | The two new definition folders |

Renamed or removed: `test_starting_gear_is_not_checked_yet` (replaced, as task 005 planned).
