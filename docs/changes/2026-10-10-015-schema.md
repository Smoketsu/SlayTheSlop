# 2026-10-10: Task 015, contract change: Junk card fields, rarity `special`, `card_removed`

Author: Agent A. Branch: `a/015-contract` (PR #39; split out of `a/015-junk-cards`). Lane: `core` (contract: `core/schema/`). **Additive only.** The state shape does not
change, so `run_state.SCHEMA_VERSION` stays 3 and no recorded hash changes.

## What changed

- **`core/schema/card_def.gd`**:
  - `RARITIES` gains `special` (gap G17, answered "accept"): Junk and Bro Move cards, never offered
    as rewards or sold in the shop.
  - Five new **optional** fields (below), new constants `LASTS`, `DEFAULT_LASTS` and
    `TRIGGER_FIELDS`, and `check()` checks them: every trigger entry needs a String `op`,
    `play_limit_in_hand` is an int 0 or more, `lasts` is one of `LASTS`.
- **`core/schema/event.gd`**:
  - New event type `card_removed`.
  - The `card_created` comment now says whether the new copy joined the run deck (definition
    `lasts` `run`) or not (`fight`). Its fields are unchanged.
- **`tests/core/schema/test_schema.gd`**: `test_junk_card_fields`.

## Why

GDD "Junk cards": when-drawn effects (Hangover, Bedbugs), an end-of-turn-in-hand effect (Burn), a
play limit while in hand (Detention), run-long versus fight-only cards (the "Lasts" column) and a
card that cannot be removed at Baileys (Regret). Content is data (CLAUDE.md), so each of these is a
field of the card definition rather than code keyed to a card id. Task 008 (Agent B) writes the six
Junk cards with them.

## Fields added, renamed or removed

| Field | Where | Type | Meaning |
| --- | --- | --- | --- |
| `on_draw` | card definition, optional | list of effects | Run in order right after this copy is drawn into its owner's hand. The owner is the actor and the target. Hangover: `[{"op": "lose_hype", "amount": 1}]`; Bedbugs: `[{"op": "self_damage", "amount": 1}]` |
| `on_end_of_turn_in_hand` | card definition, optional | list of effects | Run in order at End of turn if this copy is in its owner's hand, before the hand is discarded. Burn: `[{"op": "self_damage", "amount": 2}]` |
| `play_limit_in_hand` | card definition, optional | int, 0 or more | While this copy is in its owner's hand, that Dude may play at most this many cards this turn (`cards_played_this_turn`); further plays are rejected `unplayable`. Detention: 4 |
| `lasts` | card definition, optional | `"run"` or `"fight"` | `run` (the default): the copy is part of the run deck. `fight`: removed from the Dude's `cards`, `deck` and piles when the fight ends (Paperwork, Detention, Burn) |
| `removable` | card definition, optional | bool | `false`: cannot be removed at Baileys (Regret). Left out means `true`. Read by task 025 |
| `card_removed` | event type | `player_id`, `card_uid`, `from` | A card copy left the Dude for good: gone from `cards`, `deck` and every pile. `from`: the pile it was in, or `deck` when it was in none |

| Constant | Where | Meaning |
| --- | --- | --- |
| `RARITIES` | `card_def.gd` | Gains `special` |
| `LASTS` | `card_def.gd` | `["run", "fight"]`, the values of `lasts` |
| `DEFAULT_LASTS` | `card_def.gd` | `"run"`, what a card without `lasts` means |
| `TRIGGER_FIELDS` | `card_def.gd` | `["on_draw", "on_end_of_turn_in_hand"]`, the optional fields holding effects lists |

Nothing renamed or removed.
