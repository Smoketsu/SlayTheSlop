# 2026-10-11: Task 037, Power trigger "self_damaged" (Tough Skull)

Author: Agent A. Branch: `a/037-self-damaged-trigger`. Core lane; the contract change (the new
`POWER_WHENS` value) merged separately in #92. No data or state change.

## What changed

- **`core/combat/play.gd`**: a played card's op context gets `Ops.PLAYED_CARD_KEY` = true.
- **`core/ops/ops.gd`**: after a `self_damage` effect whose context has `PLAYED_CARD_KEY`, `run()`
  passes the actor to `Powers.reactions()` so that Dude's `self_damaged` Powers fire.
- **`core/combat/powers.gd`**: `reactions()` takes `self_damaged_id`; a `damage_dealt` with no source
  on that Dude, amount above 0, fires `self_damaged` Powers. `matching()` takes `only_player_id`, so
  only the hurt Dude's Powers fire.
- **`core/ops/README.md`**: the `self_damaged` row is no longer marked "not built".
- **`tests/core/ops/test_self_damaged_trigger.gd`** (new, 6 tests).
- **`docs/tasks/037-self-damaged-trigger.md`**: checks ticked, log, `in_review`.

## Why

Tough Skull (`tom_tough_skull`), one of the 16 new Tom cards both people accepted (#91): "Whenever
Tom takes damage from his own card, gain 3 Guard". Burn and Bedbugs use the same `self_damage` op,
so the event alone could not tell the sources apart; the played-card flag does.
