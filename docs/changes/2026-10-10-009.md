# 2026-10-10: Task 009, damage order, statuses, Broken Arm and Ick

Author: Agent A. Branch: `a/009-damage-order-and-statuses` (built on task 007's unmerged branch).
Lane: `core`. The contract part, enemy `grossed_out_skips` and `SCHEMA_VERSION` 2, is in its own
commit and its own change file: `docs/changes/2026-10-10-009-schema.md`.

## What changed

- **`core/ops/damage.gd`**: the full GDD damage order. Swole, then × Noodle, × Broken Arm (enemy
  attackers), × Exposed as one exact fraction, rounded down once, then Guard, then HP. Following
  G3, only attack damage gets steps 1–4.
- **`core/ops/guard.gd`**: Hungover (G4). Guard from cards is (amount + Chill) × `HUNGOVER_MULT`,
  rounded down.
- **`core/ops/apply_status.gd`** (new): the `apply_status` op. It stacks the four general statuses,
  breaks arms up to `arm_count`, adds Ick plus Clout once per application (G5), and applies
  Grossed Out (G6).
- **`core/ops/ratio.gd`** (new): exact fractions for multipliers, so no float is ever used.
- **`core/ops/ops.gd`**: registers `apply_status`. New `make_context()`. The op context now also
  carries `constants`, `attack` and `from_card`.
- **`core/combat/statuses.gd`** (new): who can carry which status, wear-off (G1), the Foggy draw,
  the Grossed Out and Armless skips (G6, G7), the debuff list (G27), and the constants check.
- **`core/combat/fight.gd`**: six small edits, each marked "Task 009":
  - `check_start` checks the status constants.
  - Foggy at Refresh.
  - Dude wear-off at End of turn.
  - The skip check before each enemy acts.
  - Enemy wear-off after each enemy's slot.
  - Enemy moves pass a context with `attack` = true.
- **`core/combat/play.gd`**: card context via `make_context()`. `attack` = the card is of type
  `attack`, and `from_card` = true. The header no longer says `apply_status` cards are unplayable.
- **`core/ops/README.md`**: the damage order table, G3, Hungover, and the full `apply_status` entry
  with a status table, wear-off timing, skips and events.
- **Tests:**
  - `tests/core/ops/test_damage_order.gd` (new, 7 tests): the table of all 12 combinations played
    through `Core.apply`, rounding once, the Dude attacker table, 0-arm enemies, G3, exact ratios,
    and an exhaustive check of bases 0–200.
  - `tests/core/ops/test_apply_status.gd` (new, 8 tests).
  - `tests/core/combat/test_statuses.gd` (new, 10 tests).
  - `tests/core/combat/test_fixed_seed_status_fight.gd` (new, 2 tests): a seeded bot fight won in
    turn 8 with Grossed Out, Armless and wear-off, recorded hash, identical replays.
  - `tests/core/ops/test_ops.gd`: `apply_status` is now a valid op.
  - `tests/core/combat/fixtures.gd`: status test cards, 3 enemies (Hitter, Hexer, Slime) and the
    `test_breaker` Dude.

## Why

Milestone 2 needs every number the player sees to match the GDD: the damage order, the four
general statuses and both halves of Tom's kit (Broken Arm, Ick). Gaps G1, G3, G4, G5, G6, G7 and G27
were answered "accept", so their suggested text is the rule here.

## Functions added

### `core/ops/ratio.gd` (new)

| Function | Meaning |
| --- | --- |
| `from_constant(value) -> [num, den]` | A constant (int or float) as an exact reduced fraction: 0.75 -> [3, 4]. Uses `party_scaling.gd` `to_millionths`. |
| `reduced(numerator, denominator) -> [num, den]` | The fraction in lowest terms. |
| `times(a, b) -> [num, den]` | Product of two fractions, cross-reduced so the ints stay small. |
| `floor_times(value, ratio) -> int` | value × ratio, rounded down (both 0 or more). |
| `gcd(a, b) -> int` | Greatest common divisor. |

### `core/ops/damage.gd`

| Function | Meaning |
| --- | --- |
| `run(...)` | Changed: each hit's size comes from `hit_amount`. |
| `hit_amount(constants, attacker, target, base, attack) -> int` | Damage order steps 1–4 and the step 5 rounding. With `attack` false it returns `base`. |
| `multiplier(constants, attacker, target) -> [num, den]` | Steps 2–4 as one exact fraction. |
| `broken_arm_factor(constants, broken, arms) -> [num, den]` | 1 − `BROKEN_ARM_MAX_REDUCTION` × broken ÷ arms. |

### `core/ops/apply_status.gd` (new)

| Function | Meaning |
| --- | --- |
| `check(effect, path) -> Array[String]` | Field problems: `status` is one of the six ids, `stacks` is an int of 1 or more, nothing else. |
| `run(state, effect, context, events)` | Applies the status to every living target that can carry it. |
| `_break_arms_in_place(enemy, count, events)` | Private. Broken Arm with the cap. |
| `_add_ick_in_place(enemy, amount, constants, events)` | Private. Ick and Grossed Out. |

### `core/combat/statuses.gd` (new)

| Function | Meaning |
| --- | --- |
| `check_constants(constants) -> String` | Why `EXPOSED_MULT`, `HUNGOVER_MULT`, `NOODLE_MULT` (number, 0 or more), `BROKEN_ARM_MAX_REDUCTION` (number, 0–1) or `ICK_THRESHOLD_STEP` (int, 0 or more) is unusable, or `""`. |
| `is_enemy(body) -> bool` | True for an enemy state (it has `arm_count`). |
| `can_carry(body, status) -> bool` | GDD "On" column. |
| `stacks(body, status) -> int` | Stacks of a stacked status, 0 if none. |
| `is_debuff(status) -> bool` | G27. |
| `change_stacks_in_place(body, id, status, delta, events)` | Changes a stacked status, never below 0, removes it at 0, emits `status_changed`. |
| `end_of_turn_in_place(state, events)` | G1: Dudes not Passed Out lose 1 Exposed, Hungover and Noodle Arms. |
| `refresh_draw_count(dude) -> int` | `draw_per_turn` − Foggy stacks, never below 0. |
| `after_refresh_in_place(state, dude_index, events)` | G1: Foggy loses 1 after the Refresh it affected. |
| `is_armless(enemy) -> bool` | `arm_count` > 0 and every arm is broken. |
| `deals_damage(effects) -> bool` | True if any effect's op is in `DAMAGING_OPS`. |
| `intended_move(ruleset, enemy) -> Dictionary` | The intended move's definition, or `{}`. |
| `skip_reason(ruleset, enemy) -> String` | `grossed_out`, `armless` or `""`. Grossed Out is checked first. |
| `skip_action_in_place(ruleset, enemy, events) -> bool` | Uses the skip and emits `armless` and `enemy_skipped`. True means the enemy must not act. |
| `after_enemy_slot_in_place(state, uid, events)` | G1: the enemy loses 1 of each stacked status. |
| `_is_number(value) -> bool` | Private. |

## Constants added

| Constant | Where | Value | Meaning |
| --- | --- | --- | --- |
| `ONE` | `ratio.gd` | `[1, 1]` | The fraction 1. |
| `STATUS_IDS` | `statuses.gd` | 6 ids | Every status `apply_status` accepts. |
| `STACKED` | `statuses.gd` | exposed, foggy, hungover, noodle_arms | Statuses kept as counts in `statuses`. |
| `DUDE_ONLY` / `ENEMY_ONLY` | `statuses.gd` | foggy, hungover / broken_arm, ick | GDD "On" column. |
| `DUDE_END_OF_TURN_WEAR` | `statuses.gd` | exposed, hungover, noodle_arms | What a Dude loses at End of turn (G1). |
| `DEBUFFS` | `statuses.gd` | exposed, foggy, hungover, noodle_arms | G27. |
| `WEAR_PER_TURN` | `statuses.gd` | 1 | GDD "1 stack per turn" (rule text, not tuning). |
| `FOGGY_DRAW_PER_STACK` | `statuses.gd` | 1 | GDD "Draws 1 fewer card" (rule text). |
| `DAMAGING_OPS` | `statuses.gd` | `["damage"]` | Ops that make a move "deal damage" for Armless. |
| `MULTIPLIER_CONSTANTS`, `BROKEN_ARM_CONSTANT`, `ICK_STEP_CONSTANT` | `statuses.gd` | constant names | Which `constants.json` entries the status rules read. |
| `SKIP_GROSSED_OUT`, `SKIP_ARMLESS` | `statuses.gd` | `"grossed_out"`, `"armless"` | `enemy_skipped` reasons. |
| `SKIPS_PER_GROSSED_OUT` | `apply_status.gd` | 1 | "It skips its next action" (rule text). |
| `NEEDS_TARGET`, `FIELDS` | `apply_status.gd` | true; `status`, `stacks` | Op metadata, as for every op. |
| `ATTACK_TYPE` | `play.gd` | `"attack"` | Card type whose damage is attack damage (G3). |

No tuning value from `data/constants.json` is written as a literal in `core/`. A grep for 0.75, 1.5,

only the byte-format sizes in `core/run/save/snapshot.gd`.
