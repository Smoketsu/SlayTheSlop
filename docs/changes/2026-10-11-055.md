# 2026-10-11: Placeholder sound effects and a volume setting (task 055)

Author: Agent B. Branch: `b/055-placeholder-sound`. Lane: client (plus client tests and placeholder
assets). No core, data, schema, project.godot or other contract change. No audio bus layout file:
Godot's built-in default layout always has the Master bus.

## What changed

- **`assets/placeholder/source/make_sounds.py`** (new): a deterministic generator, Python standard
  library only (`wave`, `math`, `struct`), that synthesizes the ten sounds from sine, square and
  triangle waves and fixed-seed noise. Run it with
  `python3 -I assets/placeholder/source/make_sounds.py assets/placeholder/sounds`; a second run
  writes byte-identical files.
- **`assets/placeholder/sounds/*.wav`** (new, ten files, plus their Godot `.import` files): 16-bit
  mono PCM, 22050 Hz, 0.03 to 0.90 s each, 173,088 bytes in all. Source and licence (made for this
  repository) are recorded in `assets/placeholder/README.md` "Sounds"; `client/ASSETS.md` points
  there.
- **`client/audio/sounds.gd`** (new): the one lookup table `FILES` (sound kind -> file in
  `SOUND_DIR`), `kind_for_event(event)` (which event plays which kind), `path_for(kind)`,
  `stream_for(kind)`, `stream_at(path)`, `play(kind)`, `play_event(event)` and `host()`. Fire and
  forget: `play()` starts the sound and returns the path at once (or "" when silent); nothing ever
  waits on a sound. A missing kind or file is silent, never an error. The players live under one
  node, `ClientSounds`, under the tree's root (one AudioStreamPlayer per kind on the Master bus), so
  a sound outlives the screen that started it. Under Godot's dummy audio driver (headless, tests,
  CI) the player is made but not started, since nothing can hear it and a playback left running at
  quit is reported by Godot as a leaked resource.
- **`client/audio/volume.gd`** (new): master volume and mute, saved through the client settings
  store (`client/settings/user_settings.gd`) and applied to the Master bus with AudioServer:
  `volume(path)`, `muted(path)`, `set_volume(value, path)`, `set_muted(value, path)`,
  `apply_saved(path)`, `apply(value, mute)`, `applied_volume()`, `applied_muted()`.
- **`client/settings/sound_settings.gd`** (new): the Sound row, a Volume slider (0 to 100 % in 5 %
  steps, with the percentage shown) and a Mute box. Each change applies and saves at once; showing
  the saved values writes nothing. Signal `save_failed(error)`.
- **`client/run/main_menu.gd`**: the Sound row sits under the How to play button. `setup()` takes
  an optional third argument, the settings file (`UserSettings.DEFAULT_PATH` by default). A save
  failure shows "Couldn't save settings: ..." in the menu's message.
- **`client/run/run_screen.gd`**: applies the saved volume and mute in `_ready()`; passes
  `settings_path` to the menu; every button that enters the tree under the run screen (menu, map,
  offers, fight, How to play, run-over view) plays the click when pressed, hooked through
  `SceneTree.node_added`, so no sub-screen has sound code; `send()` plays the sounds of the events
  a map or offer request returns (Dolla Bills gained).
- **`client/visual/event_player.gd`**: `play_one()` starts each event's sound
  (`Sounds.play_event()`) next to its animation. `client/fight/fight_screen.gd` is unchanged; with
  `skip_animations` no sound plays, as no animation does.
- **`tests/client/test_sounds.gd`** (new, 9 tests): see "How it was verified".

## Sound kinds (client/audio/sounds.gd)

| Kind | File | Played on |
| --- | --- | --- |
| `card_played` | `card_played.wav` | `card_played`, `bro_move_used` |
| `hit` | `hit.wav` | `damage_dealt` with `hp_lost` > 0 |
| `blocked` | `blocked.wav` | `damage_dealt` with `hp_lost` 0 and `blocked` > 0 |
| `guard` | `guard.wav` | `guard_changed` with `delta` > 0 |
| `enemy_death` | `enemy_death.wav` | `enemy_died` |
| `passed_out` | `passed_out.wav` | `dude_passed_out` |
| `click` | `click.wav` | any button pressed under the run screen (UI, not an event) |
| `dolla_bills` | `dolla_bills.wav` | `dolla_bills_changed` with `delta` > 0 |
| `victory` | `victory.wav` | `fight_ended` with `result` "won" |
| `defeat` | `defeat.wav` | `fight_ended` with `result` "lost" |

Every other event is silent.

## Fields, variables, constants and setting keys

- Added setting keys (in `user://settings.cfg`, section `settings`; never in the run state, a
  request or the run save):
  - `"master_volume"` (`Volume.VOLUME_KEY`): float 0.0 to 1.0, linear; missing or not a number
    means `DEFAULT_VOLUME` (0.8).
  - `"master_muted"` (`Volume.MUTED_KEY`): bool, true while muted; missing or not a bool means false.
- Added: `sounds.gd` constants `SOUND_DIR`, the ten kind constants `CARD_PLAYED`, `HIT`, `BLOCKED`,
  `GUARD`, `ENEMY_DEATH`, `PASSED_OUT`, `CLICK`, `DOLLA_BILLS`, `VICTORY`, `DEFEAT`, `FILES`,
  `HOST_NAME` ("ClientSounds"), `POLYPHONY` (4), `BUS` (Master), `SILENT_DRIVER` ("Dummy"),
  `RECENT_MAX` (32); static variable `recent` (last kinds played, for tests).
- Added: `volume.gd` constants `VOLUME_KEY`, `MUTED_KEY`, `DEFAULT_VOLUME` (0.8), `BUS` (Master),
  `SILENT_DB` (-80 dB, used for volume 0), `UserSettings` (preload).
- Added: `sound_settings.gd` constants `VOLUME_LABEL`, `MUTE_LABEL`, `STEP` (0.05), `SLIDER_WIDTH`
  (180 px), `Volume` and `UserSettings` (preloads); signal `save_failed(error)`; variables
  `settings_path`, `slider`, `mute_box`; private `_percent_label`, `_loading`.
- Added: `main_menu.gd` constants `SoundSettings` and `UserSettings` (preloads), variable
  `sound_settings` (the row), private `_settings_path`; optional `setup()` parameter
  `settings_path`.
- Added: `run_screen.gd` constants `Sounds` and `Volume` (preloads); functions `_on_node_added()`
  and `_play_click()`. `settings_path` now also holds the volume and mute, so it must be set before
  `_ready()` (its comment says so).
- Added: `event_player.gd` constant `Sounds` (preload).
- Added (generator): `make_sounds.py` `SAMPLE_RATE` (22050), `PEAK` (0.7), `FADE_SECONDS` (0.01),
  `NOISE_SEED` (12345), `SOUNDS` (kind -> function).
- Added (tests only): `test_sounds.gd` constants `SETTINGS_PATH`, `SAVE_PATH`, `MAX_SECONDS`,
  `LISTED`, documented in the file.
- Nothing renamed or removed.

## How it was verified

`tools/test.sh`: 538 passed, 0 failed (no leak or resource warnings at exit). `tools/test.sh sounds`:
9 passed: every listed sound is in the lookup with a loadable file under 1 s; event-to-kind mapping
(silent cases included); unknown kinds, missing files and non-sound files are silent with no error;
headless play returns at once and reuses one Master-bus player per kind; the event player starts
the sounds in order with `play()` finishing synchronously at 0 seconds; volume and mute persist in
a test `user://` file, apply to the bus and fall back to defaults on bad values; the Sound row shows
and saves; the menu's row uses the run screen's settings file, a menu button clicks, and no sound
setting reaches the run state or save; a run request gaining Dolla Bills plays their sound.
