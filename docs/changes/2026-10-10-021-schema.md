## Why

Task 021 (Gear and Brews) needs:

- A place for stat changes that last one fight. Protein Shake: "Gain 3 Swole for this fight". The
  Dude's `swole` is a run-long stat, so the fight must remember what to take back when it ends.
- A place for Smelling Salts' solo rule: "the next time you would pass out this fight, stay at 1 HP
  instead".
- Events so the client can show Gear firing, Brews being drunk, stats changing and a pass-out
  being prevented.

## Fields and events added

| Name | Where | Type | Meaning |
| --- | --- | --- | --- |
| `fight_stat_changes` | Fight state, required | Map player_id → {stat → int} | Stat changes that last only for this fight. Each is already added to the Dude's stat; when the fight ends the core subtracts it and empties the map. Stats are `gear_def.gd` `STATS`; changes are non-zero. `{}` when none. Only the rules core changes it. |
| `pass_out_saves` | Fight state, required | Map player_id → int, 1 or more | The next time that Dude would pass out in this fight, they stay at this HP instead and the entry is removed. `{}` when none. Only the rules core changes it. |
| `gear_gained` | Event | `player_id`, `gear_id` | A Dude gained a Gear. Its stat changes follow as `stat_changed`. |
| `gear_triggered` | Event | `player_id`, `gear_id`, `when` | A Gear's trigger fired; its effects follow as their own events. `when` is one of `gear_def.gd` `WHENS`. |
| `brew_used` | Event | `player_id`, `slot` (int, from 0), `brew_id`, `target_id` | A Brew was drunk. Its effects follow as their own events. |
| `stat_changed` | Event | `target_id`, `stat`, `delta`, `value` | A Dude's or enemy's stat changed. `value` is the new value. |
| `pass_out_prevented` | Event | `player_id`, `hp` | A Dude who would have Passed Out stayed up at `hp`. |
| `SCHEMA_VERSION` | `run_state.gd` | int | Changed from 4 to 5 (4 is task 013's). |
