# 2026-10-11: How to play panels and a client settings store (task 049)

Author: Agent B. Branch: `b/049-how-to-play`. Lane: client (plus client tests). No core, data,
schema or contract change.

## What changed

- **`client/settings/user_settings.gd`** (new): one small store for client-only settings on this
  machine (the How to play seen flag now; animation speed, task 047, and volume / mute, task 055,
  later). A Godot ConfigFile at `user://settings.cfg`, one section. Static API:
  `get_setting(key, default = null, path = DEFAULT_PATH) -> Variant`,
  `set_setting(key, value, path = DEFAULT_PATH) -> String` ("" or why it failed; writes
  `<path>.tmp`, then renames it over the file, as `client/run/save_store.gd` does),
  `erase_settings(path = DEFAULT_PATH)`. user:// paths only, so tests pass their own file. A
  missing or unparsable file reads as defaults. Settings never go in the run state, a request or
  the run save.
- **`client/help/how_to_play_text.gd`** (new, pure): `panels(ruleset, dude_id)` returns seven
  panels `{title, body}`: Hype and cards, Guard, Enemy intents, Bro Meter and the Dude's Bro Move,
  The map (fights), Stops along the way (Side Quest, The Tailgate, Baileys, Loot), Brews and Gear.
  Every number comes from `ruleset["constants"]` or the Bro Move card's name and text in the data;
  no digit is typed into the text. Node names come from `client/run/run_text.gd` `NODE_LABELS`.
  Baileys is only said to sell Shake.
- **`client/help/how_to_play.gd`** (new): the overlay. Dimmed full-screen backdrop that takes
  clicks, a "2 / 7" counter, title, text, and Back / Skip / Next buttons (Next reads "Let's go" on
  the last panel and closes). Skip or the cancel key closes it from any panel. Emits
  `closed(skipped)` once and frees itself. Test hooks: `press_next()`, `press_back()`,
  `press_skip()`, `shown_text()`, `page`, `panels`.
- **`client/run/main_menu.gd`**: a How to play button; `press_how_to_play()` emits the new signal
  `how_to_play_requested`. Nothing else in the menu changed.
- **`client/run/run_screen.gd`**: `show_how_to_play()` opens the overlay over everything (from the
  menu's signal, and once automatically after a New Run when the seen flag is not set) and stores
  the seen flag; `how_to_play_screen()` returns the open overlay or null. Continue never opens it.
- **`tests/client/test_how_to_play.gd`** (new): the menu button opens the panels, Next pages to the
  end and closes; Back steps back and stops at the first panel; Skip closes from every panel; the
  first New Run opens the panels once (not again on the same or a new screen, never on Continue)
  and the flag is in the settings file, not in the run state or save; every number in the text is
  read from the ruleset (constants and the Bro Move text replaced with distinct values, every digit
  run checked); glossary and Baileys wording.
- **`tests/client/test_user_settings.gd`** (new): set / get with types kept and other keys kept,
  empty and foreign files read as defaults, bad paths, keys and values refused.
- **`tests/client/test_run_screen.gd`**: `_screen()` points the run screen at its own settings
  file and marks How to play seen there, so those tests never write the real settings and still
  see the screens without the overlay.

## Why

Task 049: outside playtesters (the milestone 2 gate) need a short explanation of the game the
first time they play.

## Fields, variables, constants and setting keys

- Added setting key: `"how_to_play_seen"` (bool, in `user://settings.cfg` section `settings`; true
  once the How to play panels have opened on this machine; missing means false). Written only by
  `run_screen.gd` `show_how_to_play()`.
- Added: `user_settings.gd` constants `DEFAULT_PATH` (`"user://settings.cfg"`), `SECTION`
  (`"settings"`), `TEMP_SUFFIX` (`".tmp"`), `ALLOWED_PREFIX` (`"user://"`).
- Added: `how_to_play.gd` constants `SEEN_KEY` (`"how_to_play_seen"`), `DONE_LABEL`, `NEXT_LABEL`,
  `BACKDROP_ALPHA` (0.85, 0 to 1), `TEXT_WIDTH` (520 pixels); signal `closed(skipped: bool)`;
  variables `page` (shown panel index) and `panels` (the panels); private `_closed` and widgets.
- Added: `how_to_play_text.gd` constants `USED_CONSTANTS` and `PERCENT_CONSTANTS` (names of the
  data/constants.json values the text shows, whole and as a percent), `RunText` (preload).
- Added: `main_menu.gd` signal `how_to_play_requested`.
- Added: `run_screen.gd` constants `HowToPlay` and `UserSettings` (preloads), variable
  `settings_path` (user:// settings file, `UserSettings.DEFAULT_PATH` by default; tests set their
  own), private `_how_to_play` (the open overlay or null).
- Added (tests only): `test_run_screen.gd` `SETTINGS_PATH`, `UserSettings`, `HowToPlay`;
  `test_how_to_play.gd` and `test_user_settings.gd` constants, documented in those files.
- Nothing renamed or removed.

## Not done

- A settings file that does not parse reads as defaults, but Godot logs a ConfigFile parse error
  for it, which the test runner counts as a failure, so that case has no test.
- Animation speed (047) and volume / mute (055) settings are their own tasks; they reuse the store.
