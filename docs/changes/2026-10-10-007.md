# 2026-10-10: Task 007, combat skeleton

Author: Agent A. Branch: `a/007-combat-skeleton`. Lane: `core`.

## What changed

- **`core/core.gd`** (new): the rules core's entry point, `apply(ruleset, state, request)`, and
  `validate()`, which gives the reject reason without applying.
- **`core/combat/`** (new): starting a fight and the GDD turn flow (`fight.gd`), card play
  (`play.gd`), card piles with the G8 reshuffle (`piles.gd`), finding Dudes and enemies and handling
  0 HP (`bodies.gd`), exact party-size scaling (`party_scaling.gd`), and a run-state builder for a
  party (`party.gd`).
- **`core/ops/`** (new): the effect op registry (`ops.gd`), the `damage` and `guard` ops, and the op
  catalogue `README.md` that content agents write effects against.
- **`tests/core/combat/`**, **`tests/core/ops/`** (new): 32 tests, plus test-only content in
  `tests/core/combat/fixtures.gd`.
- **`docs/tasks/007-combat-skeleton.md`**: status `in_review`, checks ticked, log.

## Why

The client fight screen (task 018) and the bots (task 022) need a real `apply()` to call, and every
later rules task (009, 011, 013) builds on this loop. The GDD's turn flow, Guard rule (G2) and empty
draw pile rule (G8) are implemented; everything that needs an unanswered gap is stubbed and listed in
the task log.

## Functions added

### `core/core.gd`

| Function | Meaning |
| --- | --- |
| `apply(ruleset, state, request) -> {state, events, reject}` | Applies one request. Rejected: `state` is the same object passed in, `events` is `[]`, `reject` a `request.gd` code. Applied: a new state with `state_version` + 1 and the sender's `last_seq` = `seq`. Never changes its arguments. Any `request` value is accepted (non-Dictionaries are `bad_request`). |
| `validate(ruleset, state, request) -> String` | The reject reason `apply()` would give, or `""`. Reads only. |
| `_set_ready_in_place(...)` | Private: sets `ready`, ends the player phase when every Dude not Passed Out is ready. |

### `core/combat/fight.gd`

| Function | Meaning |
| --- | --- |
| `start_fight(ruleset, state, enemy_def_ids) -> {state, events, error}` | Starts a fight (not a request; `state_version` unchanged) and runs turn 1 to the player phase. On error the state comes back unchanged with no events. |
| `check_start(ruleset, state, enemy_def_ids) -> String` | Why a fight cannot start, or `""`. |
| `start_fight_in_place(ruleset, state, enemy_def_ids, events)` | `start_fight`'s work on a working copy, for code already inside `apply()`. |
| `start_turn_in_place(ruleset, state, events)` | Turn flow steps 1–2, stopping in step 3. |
| `stub_intent(ruleset, state, enemy) -> Dictionary` | STUB until task 011: the first move, aimed at the first Dude not Passed Out if the move needs a target. |
| `everyone_ready(state) -> bool` | True when every Dude not Passed Out is ready. |
| `end_player_phase_in_place(ruleset, state, events)` | Steps 4–5, then the next turn's steps 1–2. |
| `finish_if_decided_in_place(state, events) -> bool` | Sets `combat.result` (`lost` checked before `won`), phase `over`, emits `fight_ended`. |
| `_refresh_in_place`, `_enemy_act_in_place` | Private: Refresh for one Dude; one enemy carrying out its intent. |

### `core/combat/play.gd`

| Function | Meaning |
| --- | --- |
| `check(ruleset, state, dude, request) -> String` | `not_in_hand`, `unplayable`, `no_hype`, `bad_target` or `""`. |
| `card_def(ruleset, dude, card_uid) -> Dictionary` | The definition of a card copy, or `{}`. |
| `targets(state, dude, card, target_id) -> {ok, targets}` | Who a card's effects land on, and whether `target_id` is legal. |
| `resolve_in_place(ruleset, state, dude_index, request, events)` | Plays a checked card: hand out, Hype spent, `cards_played_this_turn` + 1, `card_played`, `hype_changed`, effects, then to `discard_pile` or `tapped_pile`. |

### `core/combat/piles.gd`

| Function | Meaning |
| --- | --- |
| `prepare_for_fight_in_place(state, dude_index)` | Run deck shuffled (shuffle stream) into the draw pile; other piles emptied; guard, hype, cards played 0; ready false. |
| `draw_in_place(state, dude_index, count, events) -> int` | Draws up to `count` with the G8 reshuffle; returns cards drawn. |
| `discard_hand_in_place(state, dude_index, events)` | End of turn: the hand goes to the discard pile. |

### `core/combat/bodies.gd`

| Function | Meaning |
| --- | --- |
| `dude_index(state, player_id) -> int` | Seat of a Dude, or -1. |
| `enemy_index(state, uid) -> int` | Position of an enemy still in the fight, or -1. |
| `find_alive(state, id) -> Dictionary` | A Dude not Passed Out or an enemy still in the fight, or `{}`. |
| `awake_dude_ids(state) -> Array` | Dudes not Passed Out, in seat order. |
| `enemy_uids(state) -> Array` | Enemies in the fight, left to right. |
| `is_decided(state) -> bool` | Every enemy dead or every Dude Passed Out. |
| `knock_out_in_place(state, id, events)` | At 0 HP: an enemy dies (`enemy_died`, removed); a Dude Passes Out (`dude_passed_out`). |

### `core/combat/party_scaling.gd`
