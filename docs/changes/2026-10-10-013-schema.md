# 2026-10-10: Task 013, contract change: Powers, thorns, Bro Move target, three events

Author: Agent A. Branch: `a/013-tom-card-ops-and-bro-meter` (first commit; meant to be split into
its own contract PR). Lane: `core` (contract: `core/schema/`). **Additive only**: nothing renamed,
removed or given a new meaning.

## What changed

- **`core/schema/dude_state.gd`**: two new required fields, `powers` (`[]` in `blank()`) and
  `thorns` (`0`). `check()` treats `powers` as a fifth place a card can be (each uid must be a
  key of `cards` and in none of the four piles) and reports negative `thorns`.
- **`core/schema/card_def.gd`**: new optional field `power_triggers` with `TRIGGER_SPEC`,
  `POWER_WHENS`, `POWER_TARGETS`, `WHENS_WITH_SUBJECT`, `POWER_TYPE` and `check_power_triggers()`.
- **`core/schema/event.gd`**: new event types `bro_move_used`, `thorns_changed`,
  `power_triggered`; the `card_moved` comment adds `"powers"` as a destination.
- **`core/schema/request.gd`**: new `OPTIONAL` map; `use_bro_move` may carry `target_id`.
  A `use_bro_move` without it is still well-formed, so the client's current request keeps working.
- **`core/schema/run_state.gd`**: `SCHEMA_VERSION` 3 -> 4.
- **`core/schema/README.md`**: section "Powers and thorns (task 013)".
- **Tests**: `tests/core/schema/test_schema.gd` gains `test_powers_and_thorns_are_checked`,
  `test_power_triggers_are_checked`, `test_bro_move_request_and_task_013_events`.
- **Re-recorded hashes** (state bytes change only through the two new Dude fields and the new
  `schema_version`; no rules code changes in this commit): `SAMPLE_HASH` in
  `tests/run/save/test_snapshot.gd`, `FINAL_HASH` in `tests/core/combat/test_fixed_seed_fight.gd`
  and in `tests/core/combat/test_fixed_seed_status_fight.gd`. Every outcome assertion in those
  tests still holds.

## Why

GDD "Card types and keywords": a Power "lasts the rest of the fight", so a played Power needs
fight-scoped, per-Dude state that survives a snapshot (`powers`), and data saying what it does
(`power_triggers`), so Reply Guy and Friend Zone are content, not code. Chrome Dome's "this turn,
enemies that hit Tom take 3 damage" (G9: per hit) must last from the player phase through the
enemy phase (`thorns`). Chest Bump, "Deal 20 damage. Break 1 arm on every enemy", deals its damage
to one enemy, so `use_bro_move` needs a way to name it (`target_id`).

## Fields added, renamed or removed

| Name | Where | Type | Meaning |
| --- | --- | --- | --- |
| `powers` | `dudes[]` (`dude_state.gd`) | list of `card_uid` | Power cards this Dude played this fight, oldest first. Active for the rest of the fight; out of the four piles. Emptied when the next fight starts. Only the core changes it. |
| `thorns` | `dudes[]` | int, 0 or more | Damage each enemy hit on the Dude deals back to that enemy (G9 per hit; not attack damage, G3). Reset to 0 at the Dude's Refresh. Only the core changes it. |
| `power_triggers` | card definition, optional | list of `{when, target, effects}` | What an active Power does. Only on type `power`. |
| `when` | `power_triggers[]` | text | `turn_start`, `enemy_buffed` (Guard or Swole, G10) or `enemy_grossed_out`. |
| `target` | `power_triggers[]` | text | `subject` (the enemy the trigger is about), `all_enemies` or `self`. |
| `effects` | `power_triggers[]` | list | Ops run each time it fires; the Power's Dude is the actor. |
| `target_id` | `use_bro_move` request, optional | text | Enemy uid for a Bro Move whose card targets one enemy; `""` or missing otherwise. |
| `bro_move_used` | event | `player_id`, `def_id`, `target_id` | A player emptied the Bro Meter for their Bro Move. |
| `thorns_changed` | event | `target_id`, `delta`, `thorns` | A Dude's thorns changed. |
| `power_triggered` | event | `player_id`, `card_uid`, `when`, `subject_id` | An active Power's trigger fired. |

| Constant | Where | Change |
| --- | --- | --- |
| `SCHEMA_VERSION` | `run_state.gd` | 3 -> 4 |
| `OPTIONAL` | `request.gd` | new |
| `TRIGGER_SPEC`, `POWER_WHENS`, `POWER_TARGETS`, `WHENS_WITH_SUBJECT`, `POWER_TYPE` | `card_def.gd` | new |
