## Why

Tough Skull (`tom_tough_skull`), one of the 16 new Tom cards both people accepted (#91), is a Power
that gains Guard whenever Tom hurts himself with his own card. Card data can only use a `when` value
the schema allows, and CLAUDE.md puts schema changes in their own PR before the code that uses them.
Task 037 builds the trigger itself.

## Until task 037 merges

No card data uses it until task 037 lands.
