## What changed and why

Smoketsu asked for the map to get "the same care" as the fight screen. Agent A took the task over from
Agent B (out of usage). Clicking and requests are unchanged.

- `assets/placeholder/map/` (new): floor 1's backdrop and 8 node icons (OpenAI image API, Smoketsu's
  account); sources in `assets/placeholder/README.md` "Map".
- `client/visual/map_art.gd` (new): backdrop, node icon and boss portrait lookup.
- `client/run/map_screen.gd`: backdrop, header strip, icon nodes with tooltips, bigger Boss with
  portrait, dashed trail / solid walked path / pulsing open links, a sliding Dude token, hover lift on

  tooltip, where the task moves them. `tests/client/test_map_visuals.gd` (new).

## Variables, fields and constants

Added in `client/visual/map_art.gd` (changed only by the client lane): `MAP_DIR` (folder of the map
art), `FLOOR_BACKDROPS` (floor number -> backdrop file), `NODE_ICONS` (node type -> icon file),
`FALLBACK_COLOR` (colour behind a map with no backdrop).

Changed in `client/run/map_screen.gd`: `NODE_SIZE` 120x44 -> 58x58 (an icon now); `ROW_GAP` 64 -> 60;
`BOARD_MARGIN` 16 -> 20; `LINK_COLOR`, `LINK_WIDTH`, `OPEN_LINK_COLOR`, `OPEN_LINK_WIDTH`,
`PATH_LINK_COLOR`, `CURRENT_TINT`, `VISITED_TINT`, `VOTED_TINT` recoloured for the paper backdrop.

Added in `client/run/map_screen.gd` (constants changed only by the client lane):
- `BOSS_SIZE` - the Boss node's size in pixels (96x96).
- `DASH_LENGTH` - one dash of a plain link, in pixels.
- `PULSE_SPEED` - pulses per second of the links you can take now; `PULSE_MIN_ALPHA` - their lowest opacity (0..1).
- `TOKEN_SIZE` - the Dude token's size in pixels; `TOKEN_SLIDE_SECONDS` - its slide time in seconds.
- `HOVER_SCALE` - how much a reachable node grows while hovered (1.0 = none).
- `VOTE_MARKER_SIZE` - a vote marker's size in pixels.
- `BACKDROP_TINT` - tint darkening the backdrop; `HEADER_COLOR` - the header strip's colour.
- `token_node_id`, `vote_markers`, `boss_portrait` - what was drawn, read by tests.
- `_backdrop`, `_backdrop_fallback`, `_scroll`, `_canvas`, `_overlay`, `_token`, `_token_tween`, `_clock`,
  `_ruleset_cache` - the screen's own parts and state, each commented in the file.

No core field, constant or message was added, renamed or removed.
