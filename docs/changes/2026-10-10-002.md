# 2026-10-10: Task 002, test harness, pinned Godot install and CI

## What changed

- `tools/install_godot.sh`: installs the pinned Godot 4.7.2-stable into `.tools/` after checking
  its SHA-512.
- `tools/test.sh`: the one command that installs Godot if needed, imports the project and runs
  every test.
- `tests/run_tests.gd`: the headless runner. `tests/framework/test_case.gd`: the base class every
  test extends. Both follow the interface in task 002.
- `tests/harness/test_harness.gd`: self-tests for the harness.
- `.github/workflows/tests.yml`: runs `tools/test.sh` on every pull request and push to `main`.

## Why

Nothing in `tests/core/` could run from a clean checkout. This unblocks both agents.

## Variables, fields and constants

Added (all documented in their files):

- `install_godot.sh`: `GODOT_VERSION` (pinned release, shared contract), `REPO_ROOT`, `INSTALL_DIR`.
- `test.sh`: `REPO_ROOT`, `GODOT`.
- `run_tests.gd`: `TESTS_ROOT`, `FRAMEWORK_DIR`; inner class `ErrorCollector` with `lock`, `messages`.
- `test_case.gd`: `failures` and the assertion functions listed in task 002.
- `test_harness.gd`: `HARNESS_FILES`, and fixture texts `PASSING`, `FAILING`, `RUNTIME_ERROR`, `PARSE_ERROR`.

Nothing renamed or removed.
