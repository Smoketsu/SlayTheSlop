# 2026-10-13 - task 063: art style guide and splash screens

## What changed and why

Smoketsu asked for splash screens for Side Quests and Baileys that "evoke humor and show what's going on",
and for a guide so future art stays consistent. Agent A took the task over from Agent B (out of usage).

- `assets/STYLE_GUIDE.md` (new): the look, palette, sizes, floor line, splash safe area, poses, naming,
  proposed animation conventions, the prompt template, and how sources are recorded.
- `assets/placeholder/splashes/` (new): 7 WebP splashes (5 Side Quests, `tailgate`, `baileys`), generated
  with the OpenAI image API on Smoketsu's account. Sources: `assets/placeholder/README.md` "Splashes".
- `assets/placeholder/source/generate_art.py` (new): every prompt used (splashes, and the map and UI art
  for task 061), and the conversion into game files. Excluded from exports by the existing
  `assets/placeholder/source/*` filter.
- `client/visual/splashes.gd` (new): the splash lookup by Side Quest id or offer kind, with a fallback.
- `client/run/offer_screen.gd`: shows the splash behind the choices; text and buttons sit on a dark
  panel in the lower half. Other offers are unchanged.
- `tests/client/test_splashes.gd` (new).

## Variables, fields and constants

Added in `client/visual/splashes.gd` (all changed only by the client lane):
- `SPLASH_DIR` - folder of the splash files (`res://assets/placeholder/splashes`).
- `SPLASH_EXTENSION` - file extension of a splash (`.webp`).
- `SPLASH_KINDS` - offer kinds that show a splash: `side_quest`, `tailgate`, `baileys`.
- `FALLBACK_COLOR` - colour drawn for a missing splash.
- `FALLBACK_TEXT` - words drawn on it ("(art coming soon)").
- `SAFE_TOP` - fraction of the screen height, from the top, kept clear of UI over a splash (0.5).
- `SAFE_PANEL_COLOR` - the dark, mostly opaque backing for the choices over a splash.

Added in `client/run/offer_screen.gd`:
- `splash_key` - the splash key last shown, or "" (read by tests).
- `splash_has_picture` - true when the offer showed its own picture (read by tests).
- `splash_fallback_shown` - true when the offer showed the fallback (read by tests).
- `_splash`, `_fallback`, `_panel` - the picture, the fallback rectangle and the panel the choices sit on.

Added in `assets/placeholder/source/generate_art.py`: `MODEL`, `QUALITY`, `WORKERS`, `PLACEHOLDER`, `REFS`,
`STYLE`, `SPLASH`, `ICON`, `SPECS`, `CONVERT`, each commented in the file.

No core field, constant or message was added, renamed or removed.
