# 2026-10-11: Playtest run log (task 053)

Author: Agent B. Branch: `b/053-run-log`. Lane: client (plus client tests). No core, data, schema
or contract change; nothing is added to game state.

## What changed

- **`client/run/run_log.gd`** (new): builds one record per run from the run states and events the
  client already receives, and appends it as one line of JSON to `user://run_log.jsonl`. Keys are
  sorted at every level, there are no floats, and the only clock value is `logged_at`, so the same
  seed and requests give the same line apart from it. The file is only appended to. Functions:
  `_init(state, is_resumed)`, `observe(before, result)`, `record(result, logged_at)`,
  `write(result, path)`, `is_run(state)`, and statics `encode()`, `append_line()`, `open_folder()`
  (no-op when headless), `game_version()`, `now_utc()`.
- **`client/run/run_screen.gd`** (small, localized edits): its gateway `apply()` hands every answer
  to the run's `RunLog`; `_on_run_ready()` starts a log per run (resumed for Continue) and, for New
  Run over an unfinished save, logs that save as abandoned (`_log_abandoned()`); `_take_state()`
  writes the record when the run is won or lost (`_write_run_log()`, which shows "Couldn't write the
  run log: ..." on failure and lets play go on); the run-over view gains an **Open log folder**
  button (`press_open_log_folder()`).
- **`tests/client/test_run_log.gd`** (new, 8 tests): determinism on the full fixed-seed run of
  `run_choices_drive.gd` (identical lines apart from `logged_at`, sorted keys, ints kept), rejects
  counted, one appended line per run, abandoned and resumed runs, write failure, append only, no
  personal data, Open log folder button.
- **`docs/tasks/053-playtest-run-log.md`**: checks ticked, notes on what is left out, log entry,
  `status: in_review`.

## Why

To judge the milestone 2 gate from playtesters' runs without watching them (task 053).

## Fields, variables and constants

Added in `client/run/run_log.gd`:

- Constants: `DEFAULT_PATH` (`"user://run_log.jsonl"`), `ALLOWED_PREFIX` (`"user://"`),
  `RECORD_VERSION` (1, shape of a record), `VERSION_SETTING` (`"application/config/version"`),
  `UNVERSIONED` (`"unversioned"`, the version when the setting is unset), `WON`, `LOST`, `ABANDONED`
  (the `result` values).
- Public variable: `resumed` (bool: history before this log is missing).
- Private variables: `_last`, `_fights`, `_fight`, `_rewards`, `_bought`, `_gear`, `_brews`,
  `_rejected`, `_node_id`, `_node_type` (each documented in the file).

Added in `client/run/run_screen.gd`: constant `RunLog` (preload of `run_log.gd`), variable
`run_log_path` (the log file; tests override it), private variable `_run_log` (the run's log in
memory), functions `press_open_log_folder()`, `_log_abandoned()`, `_write_run_log()`.

Added in `tests/client/test_run_log.gd` (test-only, documented in the file): `LOG_PATH`,
`SAVE_PATH`, `BAD_LOG_PATH`, `SEED`, `OTHER_SEED`, class `PhaseGateway`.

### Record keys (record_version 1)

Full meanings are in the header of `client/run/run_log.gd`.

| Key | Type | Meaning |
| --- | --- | --- |
| `brews_gained` | {player_id: [brew id]} | Brews put in slots outside fights, in order (`brew_gained` events) |
| `dudes_at_end` | {player_id: {`dude_id`, `hp`, `max_hp`}} | Each Dude at the end of the run |
| `fights` | [{`encounter_id`, `hp_after`, `node_id`, `node_type`, `result`, `turns`}] | Every fight seen, in order; `hp_after` is player_id -> HP after the request that ended it; `result` "" for a fight running at an abandon |
| `floor` | int | Floor the run ended on |
| `game_version` | String | `application/config/version`, or `"unversioned"` |
| `gear_gained` | {player_id: [gear id]} | Gear gained during the run, in order (`gear_gained` events) |
| `logged_at` | String | UTC `YYYY-MM-DDTHH:MM:SSZ`; the only clock value |
| `node_id` | String | Map node the run ended on, "" without a map |
| `node_row` | int | Its row, -1 without a map |
| `node_type` | String | Its type, "" without a map |
| `path` | [node id] | `run_state.path` of the last floor |
| `record_version` | int | `RECORD_VERSION` |
| `requests_applied` | int | `state_version`: applied requests of the whole run |
| `requests_rejected` | int | Rejected requests this client sent since the run started or was continued |
| `result` | String | `"won"`, `"lost"` or `"abandoned"` |
| `resumed` | bool | True when the history before a Continue (or of an abandoned save) is missing |
| `rewards` | [{`def_id`, `kind`, `node_id`, `player_id`, `skipped`, `taken`}] | Every choice answered; options named by card/gear/brew id, else option kind |
| `run_seed` | String | `run_state.run_seed` in decimal (64-bit safe) |
| `schema_version` | int | `run_state.schema_version` |

Nothing renamed or removed.

## Left out (the client does not have the data)

History from before a Continue (flagged by `resumed`), which card a Lift or removal acted on,
starting Gear and Brews, Brews not kept, other co-op players' rejects, any durations, and runs
quit without a later New Run. Details in the task file's Notes.
