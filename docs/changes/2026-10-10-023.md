## Why

The run flow (task 025), the map screen (task 020) and `vote_node` need a floor map and a fixed
meaning for `run_state.map` and `node_index`. G18 was answered "accept".

## How a map is made

1. Sizes of rows 1..`MAP_ROWS - 1`, each uniform in `MAP_MIN_NODES_PER_ROW..MAP_MAX_NODES_PER_ROW`.
2. Size of row `MAP_ROWS` (all The Tailgate), uniform among the sizes the Tailgate share can hold.
3. Type counts: shares of rows 1..`MAP_ROWS` rounded by largest remainder (ties in GDD table
   order), each type at least what its fixed row holds and never more than its share rounded up.
   The types left after the fixed rows are shuffled onto rows 2..`MAP_ROWS - 1`.
4. Links between consecutive rows: one of the valid non-crossing patterns (1..`MAP_MAX_LINKS`
   per node, every next-row node linked into), equally likely. Row `MAP_ROWS` links to the boss;
   the entrance links to all of row 1.

All draws come from the `map` stream in that order; nothing else in the state changes.

## Functions added (`core/run/map/floor_map.gd`)

| Function | Meaning |
| --- | --- |
| `generate(ruleset, state, floor_number) -> {state, map, error}` | Makes the map for floor `floor_number` (1 or more). Returns the state with only `rng["map"]` advanced, the map, and `""`; or the unchanged state, `{}` and the reason. Does not store the map in the state. |
| `node_id(row, column) -> String` | `"r<row>c<column>"`. |
| `index_of(map, id) -> int` | Index in `map.nodes` of the node with that id (what `node_index` holds), or -1. |
| `apportion(total, shares, fixed) -> {counts, error}` | Rounds whole-percent shares of `total` nodes to whole nodes by largest remainder, each type at least `fixed`; error when a fixed count exceeds the share rounded up. |
| `link_patterns(from_count, to_count, max_links) -> Array` | Every valid non-crossing link pattern between two rows, in a fixed order. A pattern lists, per node of the first row, the next-row columns it links to. |
| `_extend_staircase(path, degree, from_count, to_count, max_links, found)` | Private: depth-first enumeration for `link_patterns`. |
| `_read_constants(ruleset)` | Private: reads and range-checks the map constants. |
| `_fixed_counts(sizes)`, `_sum(numbers)`, `_node(row, column, type, links)`, `_refuse(state, error)` | Private helpers. |

## Found along the way

- With G18's numbers a pre-boss row of 4 Tailgates only fits a floor of 26 or more nodes, so it
  is rare (about 1% of seeds). This is the open point in the task file's notes.
- `floor` cannot be a parameter name in GDScript without shadowing the built-in `floor()`, hence `floor_number`.
