# 2026-10-11: Task 051, playtest builds (export presets and `tools/build.sh`)

Author: Agent B. Two branches: `b/051-export-presets` (the contract PR: `export_presets.cfg` and
`.gitignore` only, from `main`) and `b/051-playtest-builds` (everything else; it merges the contract
branch). Tools lane plus a build-config contract. No game rule, data, schema or state change.

## What changed

Contract branch `b/051-export-presets`:

- **`export_presets.cfg`** (new, repository root): three Godot export presets, commented with `;`
  lines (Godot drops those if the editor re-saves the file).
- **`.gitignore`**: no longer ignores `export_presets.cfg` (it was ignored since task 001) so the
  presets can be committed. `build/` was already ignored; its comment now names `tools/build.sh`.
  Export passwords, if anyone ever adds some, go in `.godot/export_credentials.cfg`, still ignored.

Work branch `b/051-playtest-builds`:

- **`tools/build.sh`** (new): installs the pinned export templates (checksum verified), exports
  every preset (or the named ones) into `build/`, and with `--check` runs the Linux build headless.
- **`tools/README.md`** (new): the tools commands; how to build; where builds land and how big they
  are; unsigned macOS and Windows builds and how testers open them; where `user://` (save and logs)
  is on Windows, macOS and Linux.
- **`tests/tools/test_export_presets.gd`** (new, 4 tests, plus its `.uid`): checks the presets
  without exporting.
- **`docs/tasks/051-playtest-builds.md`**: checks ticked, log, `in_review`.

## Why

Outside playtesters (the milestone 2 gate) need a game they can run without Godot (task 051).

`tools/` is not excluded as a whole, unlike the task's wording: the client preloads
`res://tools/data_files.gd` at runtime, and a build without it does not start. The macOS export
is blocked until `project.godot` enables ETC2/ASTC import (task 051 log).

### `tools/build.sh`

| Name | Kind | Meaning |
| --- | --- | --- |
| `--check` | flag | After exporting, run the Linux build headless (`--quit-after`); fail on a non-zero exit or any printed engine or script error. Linux x86_64 only |
| `PRESET...` | arguments | Export only these presets (names from `export_presets.cfg`); none means all. An unknown name exits 2 |
| `-h`, `--help` | flag | Print usage |
| exit codes | | 0 all exports (and check) passed; 1 an export, the check or the template install failed; 2 bad command line |
| `GODOT_VERSION` | constant | `4.7.2`, must equal `tools/install_godot.sh`'s (a test checks it) |
| `TEMPLATES_TAG` | constant | `4.7.2.stable`: Godot's templates folder name and `version.txt` text |
| `TEMPLATES_FILE` | constant | `Godot_v4.7.2-stable_export_templates.tpz` |
| `TEMPLATES_URL` | constant | `https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz` |
| `TEMPLATES_SHA512` | constant | `ca4d71c4d7b81dfc15d1a98baa07534aa95b03fdda78a0075b06672e1648d2e5f40980c9adc28d23e1b92e732ee7bf3461997aa804af74ec2fcd7a93ccb84079`, from the release's `SHA512-SUMS.txt` |
| `QUIT_AFTER_FRAMES` | constant | 300 frames for the `--check` run |
| `CHECK_TIMEOUT_SECONDS` | constant | 120 s: a `--check` run still going after this fails as a hang |
| `REPO_ROOT`, `PRESETS_FILE`, `BUILD_DIR` | constants | Repository root, `export_presets.cfg`, `build/` |
| `TEMPLATES_DIR` | variable | Where Godot looks for templates: `${XDG_DATA_HOME:-~/.local/share}/godot/export_templates/4.7.2.stable` (Linux), `~/Library/Application Support/Godot/export_templates/4.7.2.stable` (macOS) |
| `GODOT` | variable | The pinned Godot binary from `tools/install_godot.sh` |
| `check`, `wanted`, `all_presets`, `failed`, `exported`, `out_dirs`, `linux_binary`, `home`, `status`, `output` and loop variables | variables | Commented where they are set |
| `sha512_of`, `install_templates`, `read_presets`, `is_wanted` | functions | SHA-512 of a file; download, verify and install templates; list presets as name TAB path; is a preset selected |
| `build/.gdignore` | file it creates | Stops Godot importing anything in `build/` |
| `HOME`, `XDG_DATA_HOME` | environment it reads | Godot's own: where templates live on Linux. No new environment variable. `--check` sets `HOME` and `XDG_*_HOME` to a throwaway folder for the game it runs, so a tester's real save is untouched |
